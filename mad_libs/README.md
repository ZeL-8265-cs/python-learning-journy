# Mad Libs Generator 

A simple Python word game that generates a funny sentence by replacing key words in a template sentence with user input.

---

## How it works

The program reads a template sentence containing placeholders such as:

- ADJECTIVE
- VERB1
- NOUN1
- NOUN2
- VEERB2

The user is prompted to input words, and the program replaces the placeholders to generate a complete story.

---

## Features

- Reads text from a file
- Takes user input from the console
- Replaces keywords dynamically
- Generates a final story
- Saves output to a new file (`sentence.txt`)
- Replay system (play multiple times)
